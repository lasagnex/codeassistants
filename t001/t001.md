### T001 – Newton's Second Law Web App (Easy)

**Difficulty:** Easy
**Category:** Web app, UI, input validation, end-to-end testing

## Task Description
Design and implement a locally runnable web application that calculates the mass of an object from
the values of total force and acceleration using Newton's Second Law.

Formula:

```
m = F / a
```

Where:
- `m` = mass (kg)
- `F` = total force (N)
- `a` = acceleration (m/s²)

## Requirements
- Input field for Force (N).
- Input field for Acceleration (m/s²).
- Calculate button or live calculation.
- Display the result in kilograms.
- Validation for empty input, non-numeric input, and acceleration = 0.
- Reset / Clear option.
- Clean and understandable UI.
- Any modern web framework may be used; the app must run locally.

## Expected Deliverables
- The source code of the web application, runnable locally.
- The unit and end-to-end test suites, runnable with a documented command.
- Screenshots or a short video of the working app.
- A README with setup and run instructions.

## Testing
- Unit tests for the calculation logic and the input validation.
- Edge cases covered: very large and very small values, with appropriate error messages for
  invalid inputs.
- End-to-end testing: automated browser-based tests of the working app.
